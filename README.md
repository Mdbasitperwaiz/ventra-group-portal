## 🏛️ Business Verticals & Modules

1. **IT & Digital Solutions (`/it-solutions`)**
   - Custom SaaS engineering, mobile apps, AI automation, and dedicated staffing.
   - Interactive Project Cost Estimator and 30-min architecture discovery scheduler.
2. **Fresh Supply & FMCG Logistics (`/fresh-fmcg`)**
   - Farm-fresh eggs, processed poultry, fresh river fish, gourmet Ventra ice cream, and Mithila Makhana.
   - Daily Patna wholesale rate board and quick-bulk WhatsApp order launcher.
3. **Realty, Construction & Turnkey Interiors (`/realty-infrastructure`)**
   - Flagship Turnkey Construction guarantee at **Flat ₹1,999 / sq. ft.**
   - Dynamic built-up area budget calculator and technical inclusion specifications.
   - Bulk building materials supply division (550D TMT, 53-grade cement, sand, bricks).
4. **Multi-Service & Facility Maintenance (`/facility-services`)**
   - AC jet wash and repairs, RO water purification, verified manpower, and deep sanitization.
   - 30-second emergency technician booking with <60 min Patna SLA.
   - Corporate Annual Maintenance Contracts (AMC) tier comparison.
5. **Events & Hospitality Management (`/events-hospitality`)**
   - Destination royal weddings, corporate summits, and institutional catering (100–5,000+ guests).
   - Interactive event planner inquiry module and curated portfolio showcase.
6. **Healthcare & Special Ventures (`/ventures`)**
   - Medicine wholesale distribution, cold-chain biological logistics (2–8°C), and 3PL warehousing.
7. **Corporate Governance & Regional Infrastructure**
   - **Corporate Overview (`/corporate-overview`):** Vision, mission, values, and milestone timeline.
   - **Patna Hub (`/patna-hub`):** Headquarters, cold-chain yards, material depots, and 18-district Bihar network.
   - **Careers & Partners (`/careers`):** Career openings and vendor/contractor empanelment.

## 🚀 Getting Started for the Team

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+ recommended)
- `npm` (v9+)

### Installation
```bash
# 1. Clone the repository
git clone https://github.com/Mdbasitperwaiz/ventra-group-portal.git

# 2. Navigate to project folder
cd ventra-group-portal

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

### Production Build & Preview
```bash
# Compile and build production bundle
npm run build

# Preview production build locally
npm run preview
```
